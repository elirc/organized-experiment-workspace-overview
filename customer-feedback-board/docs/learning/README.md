# Learning Docs

This folder teaches how to study Customer Feedback Board as a realistic product workflow codebase.

## Files in this folder

| File | Use it for |
| --- | --- |
| `how-to-study-this-codebase.md` | The four study passes, each with a goal and a self-check |
| `file-reading-order.md` | Which docs and source files to open, in order, with what to look for in each |
| `feature-slices.md` | Which features are fully built and which are only partly built |
| `how-a-junior-should-review-this-project.md` | Review questions with answers located in the code |
| `build-journal.md` | How the project was built, stage by stage, and why |
| `pr-slices.md` | How the work could be split into reviewable pull requests |

## Suggested order

1. `how-to-study-this-codebase.md`
2. `file-reading-order.md`, while you actually open the files
3. `how-a-junior-should-review-this-project.md`, once you have traced one vote and one status change
4. `build-journal.md` and `pr-slices.md`, for the history and the delivery plan

The workspace-level guide, `../../../CODEBASE-STUDY-PATH.md`, covers the same app with line-referenced traces, a verified findings table and an exercise ladder. These learning docs were last checked against the code on 2026-10-06; line numbers refer to this workspace's copy of the app and will drift if the code changes.
